# Paradise Nursery - e-Plant Shopping Application

Bem-vindo ao repositório do **Paradise Nursery**, uma aplicação web de carrinho de compras em React e Redux desenvolvida como Projeto Final do curso.

## Sobre o Projeto
O aplicativo permite que os usuários naveguem por diversas categorias de plantas de casa, visualizem detalhes (imagem, nome, descrição e preço) e gerenciem seu carrinho de compras dinamicamente com cálculo automático de subtotais e valor total.

## Tecnologias Utilizadas
- React (Componentes Funcionais, Hooks e Estado)
- Redux Toolkit (`createSlice`, `configureStore`)
- CSS3 Responsivo
